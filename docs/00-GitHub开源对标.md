## 结论

此前把排期、自动发帖或单一渠道工具列为同类项目，判断不准确，现已替换。  
**此前调研将 [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel) 作为产品结构对标：它把创作者账号画像、内容发现、选题规划、作品生产、项目归档、渠道适配与归因学习放在同一个 Agent 工作台中。当时选用其 Hermes 适配版，现已由 Multica 二次开发路线取代。**

本项目应参考 Easel 的“持续经营内容系统”结构，而不是参考任何社媒发布器的账号接入或自动排程能力。

## 什么才算本项目的同类

一个项目至少应同时具备下列多数能力，才可称作本项目的工作台级对标：

1. 按创作者/账号维护长期定位、风格、受众与记忆。
2. 从热点、收藏、网页、文件等输入中发现和解释选题。
3. 将选题推进为可编辑、可追溯、有版本的正式作品，而不止生成一段聊天文本。
4. 让创作、审核、交付、发布记录和反馈学习处于同一项目状态链。
5. 能由 Agent、Skill 或本地工作流调用，并把产物写回工作台。

排期工具、海外社媒发布器、单个小红书写作 Skill、爬取/转录工具只覆盖其中一环，均不是同类产品。

## 主对标：Easel

| 维度 | Easel 已有做法 | 对本项目的意义 |
|---|---|---|
| 长期账号经营 | Account Profile 保存定位、风格、受众、平台、偏好、边界与长期记忆 | 首版应有可版本化的 IP 档案；AI 的建议须能回指档案和历史证据 |
| 内容发现 | Discover 把趋势、热点和研究作为创作入口 | “今天写什么”必须给出来源、时效与匹配理由，而非随机推荐 |
| 规划 | Plan 连接内容日历、选题与项目 | 选题、制作任务、人工发布提醒要与同一作品关联 |
| 创作产物 | Create 支持文字、图片、视频等生产，并归档项目输出 | Agent 结果应形成可编辑作品与版本，不留在会话里 |
| 多渠道适配 | 为不同平台制作内容版本和交付物 | 以公众号、小红书、抖音、视频号的渠道稿和制作包建模 |
| 学习闭环 | Attribute 使用内容表现回写账号记忆 | 人手录入实际结果，AI 生成可编辑复盘并提出下一轮建议 |
| Agent 形态 | 提供 CLI、Web、Skills、Profile 与输出目录等工程边界 | 本项目可沿用“Web 工作台 + 受限 Agent 接口 + 可追溯产物”的分层 |

Easel 采用 Apache-2.0 许可证，并且仓库包含 Web、CLI、Skills、Profiles、Outputs 等完整工程结构。它不是一个仅有概念页的案例，适合后续做源码级架构阅读和本地试运行候选。

### 应吸收的结构

- 一份账号/IP 档案贯穿发现、创作和学习，而不是每次临时拼提示词。
- “发现、规划、创作、交付、学习”是可回溯的业务状态，产物归档到项目而不是散落在聊天记录。
- Agent/Skill 是工作台能力的调用入口，不能绕过作品版本、人工审核和事实记录。
- 表现数据只改变后续建议或产生新的档案修订；保留原始录入、旧结论和新版复盘。

### 不应照搬的部分

- Easel 的直接发布、登录或平台自动化能力不在本项目范围。这里的交付止于经审核的渠道包、人工提醒与手动发布登记。
- 本项目只针对中国社交媒体。首版固定公众号、小红书、抖音、视频号，不按海外平台 API 设计数据模型。
- 媒体生产的广度应由真实创作流程决定；首版优先保障资料依据、作品编辑、版本、审核、手动记录与 AI 复盘。

## 建议的开源利用方式

当前不应直接选用或克隆任何项目作为实现结论。若要推进源码验证，按以下顺序进行：

1. 先以 Easel 为单一主样本，读取其数据对象、项目目录、工作流状态和 Agent/Skill 边界。
2. 用真实的中国平台创作样例，验证“素材 → 选题 → 作品版本 → 人审交付 → 人手记录 → AI 复盘”能否完整走通。
3. 对照 `agent-xiaohongshu-workbench` 验证“小红书账号—热点—选题—作品预览—人工确认”的本地工作流；直接发布分支不进入范围。
4. 对照 ArcReel 验证视频作品、素材资产与制作包的对象关系；仅作架构参照，不能因其高星而忽略 AGPL-3.0 约束。
5. 仅把 OpenBiliClaw、Agent-Reach 等项目视为可替换的输入/研究能力；不得让其登录状态、抓取方式或浏览器自动化成为产品必要条件。
6. 若考虑 Fork 或复用代码，再单独做许可证、依赖、数据安全、平台规则与维护成本审查。

本次仅进行了公开资料的只读研究；未克隆、安装、运行、Fork、修改或接入上述第三方项目。
