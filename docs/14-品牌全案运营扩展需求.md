# 品牌全案运营扩展需求

日期：2026-09-13。状态：用户确认需求，尚未实现。作为工作流、PRD、技术方案和验收的补充，不改变既有 R-001～055 编号。

## 范围与优先级

本轮将节日/活动节点联动选题、品牌/账号诊断与行业竞品监测纳入正式开发范围；执行顺序需结合依赖拆解，不自动提升为所有基础模块之前的前置任务。直播与营销活动可配置 SOP 登记为待办，尚不展开具体业务模板。

沿用中国社交媒体、一个品牌一个工作空间、账号专属资料按任务授权、手动发布和手工录入真实运营数据、AI 复盘及人工采纳的既有决定。平台搜索优化和 ROI 专项未在本轮确认。

## R-056 · 节日、品牌活动与营销节点联动选题

- 品牌空间内管理节日、行业节点、品牌活动与营销节点，记录名称、类型、起止日期、时区、适用账号、运营目标、准备提前量、资料引用及状态。
- 用户可手工创建或导入后确认；来源、日期不确定性和修改历史可查。首版不承诺自动提供完整节日日历，联网获得的日期须显示依据及确认状态。
- 节点形成关联选题候选，说明与账号受众、品牌目标、内容支柱和现有素材的关系，标示准备时间、撞期、资料缺口及重复风险。运营目标和账号角色由使用者配置。
- 采用候选后创建或关联简报、可选项目及内容排期；推荐本身不自动启动创作、批准或发布。
- 节点改期、取消时提示受影响的选题与排期，由人决定调整；不覆盖已运行快照、作品版本或真实发布记录。

## R-057 · 品牌/账号经营诊断

- 根据用户选择的品牌目标、账号配置、内容支柱、发布节奏、作品、人工指标和反馈生成诊断。支持账号报告及授权范围内的品牌汇总。
- 诊断至少区分定位与表达一致性、内容覆盖、节奏、表现变化、受众反馈和执行流程问题；维度可配置，不预设行业运营角色。
- 报告记录分析范围、时间窗口、数据完整性、原始依据、AI 判断、替代解释、局限和行动建议。未知数据保持未知，不伪造分数，不把相关性写成因果结论。
- 无数据时显示可诊断范围与补录待办，允许定性分析；不能生成有数据支持的增长结论。不同平台指标不直接混合排名。
- 建议可由人采用为账号配置修改、选题或待办；长期经营记忆仍须人工采纳。运营诊断与文档13的开发诊断面板分别建模和展示。

## R-058 · 行业与竞品监测

- 品牌内配置行业关键词、竞品对象、关注主题、用户指定网页和 RSS/Atom 源，支持启停、频率配置与手动刷新。
- 通过已授权且可用的订阅/网页读取/搜索工具收集资料，保存链接、获取时间、适用条件和变化依据；账号私有资料仍受授权限制。
- 聚合更新、去重并区分新内容、内容变化及重复转载；发现摘要记录事实与 AI 判断，支持相关性评估及转为素材、研究任务或候选选题。
- 明示每次监测实际覆盖的来源、时间范围、失败与缺失。不承诺全网覆盖、平台内部数据抓取或准确算法洞察；无新结果不能在采集失败时显示“没有变化”。
- 监测遵守执行预算、权限和运行状态；执行方离线时显示待执行或失败并允许重试，不自动切换模型或计费方式。联网范围受运行授权约束，本地模式不执行网络监测。

## R-059 · 直播、营销活动可配置 SOP（待办）

复用已有版本化 SOP 与项目/待办能力，后续补充直播准备、素材/脚本、人工执行、交付核对、活动收尾和复盘模板。具体步骤、角色、目标、交付物由运营者配置。

本项尚待拆解与验收细化；不引入平台开播控制、自动直播、平台发布或投放执行。已有强制人审及资料权限不因模板改变而取消。

## 工作流与技术落点

节点/监测发现 → 授权素材与候选选题 → 人工选择 → 已有研究/创作/审核链路 → 手工发布与数据录入 → 经营诊断/复盘 → 人工采纳建议。

- 节点由选题/日历领域拥有，保存节点版本；运行快照引用确定版本。
- 监测源配置、采集记录、内容快照复用来源领域及连接器；选题领域通过公开接口消费发现，不读取其他模块私有表。
- 诊断由复盘领域拥有，复用人工观测、作品引用、AI 产物版本及采纳机制；品牌汇总先授权，再读取账号资料。
- 数据库不新增外键/级联；必要关系由应用事务校验。新增索引遵守现有独立并发索引迁移约束。
- 耗时操作使用可恢复异步任务，记录运行输入、去重依据、预算、错误及覆盖情况。复用完整诊断规范，不另建日志体系。
- 原生日历/选题页接入节点，研究/来源页接入监测，运营复盘页接入诊断；Skill 规定分析方法，服务端负责授权、状态与持久化。
