# Spec Kit 全局安装记录

用户明确要求将 https://github.com/github/spec-kit 安装到全局。
采用官方 README 的 uv tool install 方式，GitHub 最新发布核对为 v1.0.6。

- 执行：uv tool install specify-cli --from git+https://github.com/github/spec-kit.git@v1.0.6
- 来源提交：96c9bd657bfd5de0d651a6165084932b7304ac99
- 用户级全局命令：C:\Users\13900\.local\bin\specify.exe
- specify version：1.0.6，Python 3.12.9，Windows AMD64。
- specify check：退出0，ready；识别到 Codex CLI、Claude Code 等已安装工具。
- 用途：跨项目调用 Specify CLI；项目模板仍需在目标项目单独初始化。
- 未对当前 Loretide 运行 specify init，未修改现有项目规则或业务代码。
- 卸载命令：uv tool uninstall specify-cli。
