# 开发子任务模型选择：官方文档核对

用户要求核查 OpenAI 官方文档，重新判断开发子任务是否需要 GPT-5.6 High。

本次使用 OpenAI Docs 技能及官方文档工具，实际搜索并读取：

- https://learn.chatgpt.com/docs/models ：模型选择、Astra/Sol/Terra/Luna 分工与 reasoning effort。
- https://developers.openai.com/api/docs/guides/reasoning ：Low/Medium/High 的适用任务及速度、token 使用权衡。

官方依据：Terra 定位日常工作与推理、工具使用；Sol 面向复杂、模糊和高价值工作；应从满足质量要求的较低推理强度起步。Medium 适用于需要规划、判断的 agentic coding；High 面向复杂调试和更难的多步任务，不是所有开发的必要配置。

针对本项目的判断（不是官方对本项目的评测）：下一项限定为诊断包实际下载、断线恢复及关联测试修复，架构与验收已有约束，建议开发子任务从 **GPT-5.6 Terra / Medium** 开始。遇到难定位的并发、重连状态机或权限问题，再提高强度或换 Sol；主任务负责跨模块审查。此前将 Sol / High 作为统一起点偏重，予以修正。

本次没有创建新任务、改变模型、调用付费模型做基准测试或安装远程模型客户端。模型与推理强度不决定 VPS 上是否部署模型；这里讨论的是操作远程源码与测试环境的 Codex 开发任务。
