## 发现与处理

首次编译工作区 issues 页面时 Web 容器 OOMKilled=true，原内存上限2560MiB导致进程终止。现场可用内存约5.9GiB，将专用 Web 上限改为3584MiB、Node堆上限2560MiB，仅重建本项目 Web。应用提交8e3c1c5；配置已传至服务器。

首次调整后容器一度运行且OOM=false，检查时约2.183GiB、CPU约160%，随后再次OOM退出。不能将该短时状态记为修复通过。进一步改为Web上限5120MiB、Node堆3072MiB并重建，仅单独验证Web；不得在未检查资源余量时并行其他大型构建。

登录页的开发错误提示来自未认证 /api/me 的401日志；未将其误认为验证码登录失败。首次容器退出导致浏览器连接重置；错误页的 data URL 被浏览器工具限制读取，没有绕过浏览器安全设置。
