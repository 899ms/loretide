# Database test classification: read-only static inventory

## Method and limitation

This inventory read source text only. It did not connect to a database, execute
a package test, compile a test package, or modify the repository.

For each `Test*` function, the scanner looked for a direct reference to the
current package's known DB-root globals. `internal/handler` globals were
`testHandler`, `testPool`, `testUserID`, `testWorkspaceID`, `testRuntimeID`, and
`dbfx`; `cmd/server` globals were `testServer`, `testPool`, `testToken`,
`testUserID`, and `testWorkspaceID`.

This is classification input only. A non-matching test can call a helper that
uses the database, and a matching test may isolate only one subcase. It is not
authorization to add build tags or split files. The Phase 2 implementation must
audit/compile every classification result.
