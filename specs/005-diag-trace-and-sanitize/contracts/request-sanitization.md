# Contract: 请求头与路径/URL 脱敏

供**全部 sink 与导出复用的同一套规则**，无绕过路径（spec FR-007）。

## 请求身份（`Event.route`）

- 形状：`<METHOD> <路由模板>`，例如 `GET /api/content-diagnostics/events`。
- 路由模板取自注册时的模式（含 `{id}` 这类占位符），**不是**实际路径，因此不含任何用户取值。
- 查询串整体不记——不记取值，也不记键名。
- 取不到路由模板时（未匹配任何路由）写 `""`，**不**回退到实际路径。

## 请求头准入

- **allowlist**：列举允许项，其余一律不记。
- 名称比对大小写不敏感。
- 未准入的头：**名称、取值、片段、长度都不出现**。
- 同名多值：不拼接，整体按未准入处理。
- `Authorization`、`Cookie`、`Set-Cookie`、`X-CSRF-Token` 等凭据类头不在名单上。

## 入站 trace 的关联属性（`Event.upstream_trace`）

- 只有校验通过且未被采信为父级时写入；被采信时不写。
- 值为固定形状的 W3C trace-id，不承载自由文本。

## 通用规则

| 规则 | 说明 |
|---|---|
| 整体丢弃优于部分保留 | 不输出截断前缀、长度、哈希等可还原或可关联的片段 |
| 与既有字段级白名单同口径 | `oneOf()` / `token` / `hexID` 的行为不变，本功能只增加两条具名规则 |
| 导出复用 | 预览与下载两条路径得到同一套脱敏结果，`redacted` 为真 |

## 负例（必须有测试）

| 输入 | 期望 |
|---|---|
| `Authorization: Bearer <token>` | 事件与导出包中不出现该头的名称或取值 |
| `authorization`（小写） | 同上——大小写不影响判定 |
| 路径 `/api/x/9f2c…/detail` | 记 `GET /api/x/{id}/detail`，不出现该 id |
| 查询串 `?token=abc&q=secret` | 不出现 `token`、`abc`、`q`、`secret` |
| 路径里塞令牌 | 按未准入处理，不因为「它在路径里」就当安全 |
| 同名多值请求头 | 整体不记，不因拼接泄漏未准入部分 |
| 超长 URL / 超多请求头 | 有界；超出部分整体丢弃而非截断保留 |
