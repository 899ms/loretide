# 手动验收清单：品牌级自动预检开关（LT-015）

按 constitution 原则 II，界面呈现不做自动化。本次交付**全部未执行**，等待用户在本机浏览器确认。

**前置**：一个隔离实例，至少两个品牌（工作区），当前账号在两个品牌里都是 owner 或 admin。

**范围提醒**：本卡只做**配置**。开关不驱动任何预检运行——那是 EP-06。所以这里验的是「值对不对、存不存得住、账号侧有没有漏口子」，**不是**「预检跑没跑」。

## 记录方式

- 每条只有三种结果：**通过** / **未通过** / **未执行**。
- **未执行不填通过。**
- `P-6` 若在账号页发现任何预检相关控件，记「未通过」并写下它在哪一段——那是 SOP 明确禁止的东西，不是小问题。
- `P-3` 若刷新后变回开，记「未通过」并写明关闭后到刷新之间做过什么——这条对应 `false` 被当成「未设置」的那类缺陷。
