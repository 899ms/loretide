# 合同：账号表达配置

## 1. 字段

| 键 | §3.1 的名字 | 形状 |
|---|---|---|
| `audience` | 受众 | 文本 |
| `common_questions` | 常见问题 | 文本 |
| `experience` | 经验与可信依据 | 文本 |
| `positioning` | 定位主张 | 文本 |
| `content_pillars` | 内容支柱 —— **即最小可开始条件里的「内容方向」**（Q3 裁决） | 文本 |
| `expression_style` | 表达风格 | 文本 |
| `forbidden_expressions` | 禁用表达 | 文本 |
| `content_goals` | 内容目标 | 文本 |
| `primary_channels` | 主要渠道 | 列表，取值来自 `ip-profile` 的 `Platforms` |
| `weekly_hours` | 每周可投入时间 | 整数（小时） |
| `style_samples` | 风格样本 | 列表（**仅文本粘贴**；文件上传属 W-03） |

每一项都带 `status`：`pending`（待补充）或 `confirmed`（已确认）。

## 2. 状态规则

- **默认 `pending`。** 未填的字段就是待补充，不是「已确认为空」。
- **空值强制 `pending`。** 客户端把一个空字段标成 `confirmed`，服务端降回 `pending`。只下调状态，**永不写入内容**。
- **系统永不填默认内容。** 空就是空：不推断、不填示例、不填「暂无」。§3.1 点名的四类——身份、经历、成绩、商业承诺——各有一条负例。

## 3. 一条 revision 一份档案

确认写入 `content_account_revision` 的新一行，同时带 `profile` 与 `persona_prompt`。

**只改其中一半时，另一半从当前版本结转。** 否则确认完档案再改一次提示词，就会把档案清空——加列之后最容易出现、也最安静的一种数据丢失。两个方向各有用例。

LT-012 的性质全部继承：只插不改不删、旧版逐字节不变、并发有界重试后 409。

## 4. 最小可开始条件

```
Readiness { CanStart bool, Missing []string }
```

四项，**只计入 `status=confirmed` 且非空的字段**（裁决追加）：

| 项 | 满足条件 |
|---|---|
| 受众 | `audience` confirmed 且非空 |
| 内容方向 | `content_pillars` confirmed 且非空 |
| 渠道 | `primary_channels` confirmed 且至少一个 |
| 可投入时间 | `weekly_hours` confirmed 且 **> 0** |

**返回缺失项清单而不是一个布尔**：调用方要能说出还差什么，而不是只说「不行」。

**其余字段不参与**——常见问题、经验、定位主张、表达风格、禁用表达、内容目标、风格样本都是内容质量的输入，不是开始的门槛。

**`weekly_hours` 为 0 不算满足**：确认「每周 0 小时」等于说没有时间开始。这是一处**解释**，不是原文直述，记在这里以便被推翻。

## 5. 中性表达

```
UsesNeutralExpression(profile) bool   // 没有任何已确认且非空的风格样本时为真
```

- **算出来的，不是一个开关。** 两份真相会漂移。
- **不参与**最小可开始条件，**不阻止**任何写入——§3.1：「不阻止记录素材或人工写作」。

## 6. 提炼：本卡不实现

「Agent 可从输入中提炼候选档案，逐项展示提炼依据」在 constitution 原则 IX 下**不实现**：真实执行器禁用。

本卡**不调任何模型、不产生任何提炼结果、不填任何字段**。接口层不留一个会悄悄返回假数据的洞；界面上的「暂不可用（执行器禁用，EP-08 接入）」位属于第二个 PR。

## 7. 不变量

| # | 不变量 |
|---|---|
| A1 | 确认一次产生一版，承载整份档案 |
| A2 | 旧版本逐字节不变且可读 |
| A3 | 空字段读出来是空 + `pending`，永无系统写入的内容 |
| A4 | 只改提示词不清空档案；只改档案不清空提示词 |
| A5 | 最小可开始条件只计 confirmed，且四项齐备才为真 |
| A6 | 缺失项清单说得出缺哪几项 |
| A7 | 无已确认样本即中性表达，且不阻止写入、不参与开始判定 |
| A8 | 渠道取值必须在 `Platforms` 内，否则 400 |
| A9 | 非法结构回 400 诊断错误对象，存储不变 |
| A10 | 越权 404，与不存在同形 |
| A11 | 本卡之前写的旧版本读出来档案为空、全 `pending`，不报错 |
