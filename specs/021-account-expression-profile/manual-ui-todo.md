# 手验 Todo：账号表达配置页（specs/021 第二个 PR）

宪法 II 禁止 UI 单测与自动浏览器验收，所以下面这些项**没有自动化证据**，必须由人在浏览器里看一遍。
勾选框只代表「已看过」，不代表验收通过（宪法 X）。
