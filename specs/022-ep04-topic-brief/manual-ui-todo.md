### 自动覆盖

- 真实路由表包含选题卡与简报端点，且未登录请求由认证中间件拒绝。
- 带路径参数的读取会穿过真实中间件，并证明选题卡 ID 不会被工作区上下文值替换。
- 非成员统一得到 workspace-core 的 404，拒绝写入技术日志。
- 品牌删除事务同时清理 `content_topic_card` 与 `content_brief_revision`；失败回滚时原行保留，邻居品牌不受影响。
- 品牌删除已提交后，建卡、四个决策动作、`start` 与追加简报一律被删除栅栏拒绝，两张表与审计表都不新增行。

最后三项需要独立 PostgreSQL 测试库；没有相应环境变量时测试明确记为 SKIP，不得记为通过。
