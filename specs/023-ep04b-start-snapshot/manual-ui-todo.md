## 已知边界（本 PR 明确未做）

- **「记住上次选择」不是原子的**：写回账号偏好是开始成功之后的一次独立请求（后端的开始事务不写它）。它失败只影响下一次开始的初值，**不影响已经固定的快照**——快照里的两个范围字段在开始那一刻就写死了。
- **开始记录按简报版本列出，不是按卡**：后端今天只提供「某一版的全部开始」，所以区块显示的是**当前选中版本**的次数。按卡汇总要等一条按卡列出的端点。
- **项目是自由文本**，不校验它是否对应一个真实的 Multica 项目。
- 桌面端未接线、侧边栏无入口（与 `/topics`、`/accounts`、`/diagnostics` 一致）。
- 「已开始的运行继续看到旧配置」只交付**结构保证**（快照只插不改、以 `snapshot_id` 被引用）；「某次运行确实读到了它钉的那一份」的行为断言要等 `agent-workflow` 落地。
