# 手动 UI 清单（024 work-editor 人工写作）

页面入口：选题卡详情页 `/{workspaceSlug}/topics` → 选中一张卡 → **「开始运行」区块之后**的「作品」区块。选题卡列表不加入口。

**交付形态与派单措辞的偏差（须知悉）**：派单写的是「作品页文档列表、文档编辑页」。本仓库的内容页（`/diagnostics`、`/accounts`、`/topics`）一律是**单路由 + 页内选中**，`packages/core/paths` 没有它们之间的跳转助手，彼此也不互相链接。因此「作品列表 / 文档列表 / 文档编辑 / 历史 / 对照」全部作为**同一张选题卡详情页上的区块**逐级展开，而不是三条新路由。这也与 024 裁决把入口定在「选题卡详情页 start 之后的区块」一致。若主任务要求独立路由，需要先决定这三条路由的 `paths` 助手与侧边栏口径。

存储与接口由 PR 1（#145）交付，本清单只覆盖页面。全部条目**状态：未执行**——只能由主任务在浏览器逐条验收；本会话不做 computer use，不写 UI 单测（宪法 II）。

## 复用的既有组件（未新增控件、未改样式）

`SettingsSection` / `SettingsCard` / `SettingsRow` / `SettingsSaveState`（`@multica/views/settings`）、`Button` / `Input` / `Textarea` / `Select`（`@multica/ui`）。对照视图用两个只读 `Textarea` 并排，**没有引入 diff 库**（T032）。

## 已知边界（本 PR 明确未做）

- **自动保存是「停手约 1 秒后落地」**，不是逐字提交，也没有离开页面时的强制 flush；快速切换文档可能丢掉最后一次未落地的改动。这是本切片的已知取舍，不是缺陷掩盖。
- **没有冲突合并**：两个人同时编辑同一份文档，后写的覆盖先写的（服务端是最后写入者胜）。本切片不做多人协同。
- **三个 AI 入口不可用**是结构性的（宪法 IX 执行器禁用），EP-08 接入前不会有候选。
- **「已审核 / 交接 / 发布版本永不删除」只有结构保证**：版本表没有 DELETE 路径，但「某一版确实被交接过」要等后续卡。
- 桌面端未接线、侧边栏无入口（与 `/topics`、`/accounts`、`/diagnostics` 一致）。
