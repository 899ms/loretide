- [ ] Web / 导入已发表作品：从今日工作台进入导入页，分别在 320、768、1024、1440 px 宽度确认表单、四步状态与作品列表无横向溢出，键盘可依次到达所有输入和按钮。
- [ ] Web / 完整导入：填写正文、渠道、发布时间、平台账号与链接后提交；确认四步依次变为“已完成”，作品列表显示“历史导入”，打开作品后正文和唯一的 `imported` 版本可见。
- [ ] Web / 第四步失败与重试：链接留空提交；确认前三步已完成、第四步失败，链接字段被标记，页面说明已创建对象不会删除；补链接后“从失败步骤重试”只完成第四步且不产生第二件作品或文档。
- [ ] Web / 正文上限：粘贴超过 200000 个字符的正文；确认提交按钮不可用、页面说明尚未创建任何对象，刷新作品列表没有新增项。
- [ ] Web / 历史标识：在导入页作品列表同时查看历史导入作品和正常作品，确认只有历史作品显示标识；在今日工作台“待补录的反馈”确认对应记录也显示该标识。

- [ ] Web / 四语言：依次切换英文、简体中文、日文、韩文，确认导入页、历史标识及“暂无个人表现数据”均有对应文案且无原始 key。
