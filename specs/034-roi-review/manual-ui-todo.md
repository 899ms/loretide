# 手动 UI 清单（034 成本、线索、成交与 ROI 复盘）

页面入口：侧栏「ROI 复盘」或 `/{workspaceSlug}/roi-review`（命令面板搜「复盘」「roi」也能到）。页面顶部一排按钮切换五个区块：「成本」「线索」「成交」「导入」「复盘报告」；切走的区块只是隐藏，填了一半的表单和打开的报告还在。

存储、计算与接口由 PR 1～4 交付；本清单只覆盖 PR 5 的页面。全部条目**状态：未执行**——由用户或主控在浏览器逐条验收；执行会话不做 computer use，不写 UI 单测（宪法 II）。

复用的既有组件：`SettingsContent` / `SettingsTab` / `SettingsSection` / `SettingsCard` / `SettingsRow` / `SettingsSaveState`（`@multica/views/settings/layout`）、`PageHeader`、`Button` / `Input` / `Textarea` / `Select` / `Checkbox`（`@multica/ui`）。区块切换用 `Button` 的 `brand` / `outline` 两个既有变体。不新建控件，不设颜色；「不可计算」、负回报、「来源不明 / 未判断」等行用 `text-muted-foreground`。

## 本清单最要紧的四条

**U-12、U-22、U-24、U-30。** 它们对应 D14-V12 的固定样例、证据与判断分开、品牌不重复计数、以及「不可计算」不被显示成 0。这四处任何一处在界面上走样，报告就会误导人，而且不会有任何报错。
