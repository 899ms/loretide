# 手动 UI 清单（036 平台搜索优化）

页面入口：`/{workspaceSlug}/search-optimization`，三个区块：「搜索主题」「优化建议」「搜索表现」。作品编辑器页另有一个「搜索优化」链接。

存储与接口由 PR 1～3 交付；本清单只覆盖 PR 4 的页面、PR 2 的版本动作文案，以及 D14-V15 的浏览器闭环。全部条目**状态：未执行**——由用户或主控在浏览器逐条验收；执行会话不做 computer use，不写 UI 单测（宪法 II）。

复用的既有组件：`SettingsSection` / `SettingsCard` / `SettingsRow`（`@multica/views/settings/layout`）、`Button` / `Input` / `Textarea` / `Select`（`@multica/ui`）。不新建控件，不设颜色。

## 本清单最要紧的五条

**U-05、U-13、U-16、U-24、U-30。** 它们对应「没有数据就是未知」、采用后旧批准不带过去、放弃什么都不改、单次观察不是排名，以及 D14-V15 的浏览器闭环。前四处任何一处在界面上走样，页面就会误导人，而且不会有任何报错。
